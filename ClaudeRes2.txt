The new identity: 'The Register'
CampusLink should look like an institutional placement register that learned to explain itself: ruled paper, stamped decisions, margin notes. It suits a placement cell (stamps and registers are how Indian offices actually run), nobody else at the hackathon will look like it, and it is cleaner than cards because most boxes disappear.
Six devices, used everywhere and nothing else:
1. Ruled, not boxed. Hairline rules separate sections. Only 'objects' get a paper surface.
2. Stamps for decisions. VERIFIED, REJECTED, SHORTLISTED, CLASH, RESOLVED, ACCEPTED. Rotated -2°, mono caps, 1.5 px border, they thud in when a decision happens.
3. Margin notes for AI. An italic serif note with a small mono 'AI NOTE' label. Key phrases get a highlighter swipe behind them.
4. The thread. One 2 px ochre line used for the landing pipeline, the application stage tracker and the interview timeline.
5. Mono for data. Roll numbers, CTC, dates and scores in IBM Plex Mono; big numerals in Newsreader.
6. Paper grain. A 4% noise overlay on the bone background so it never looks flat.
The palette stays, used with more conviction: ochre appears as small solid areas (the thread, highlighter, match bars, button hover fill), and ink appears as full-bleed blocks for contrast (sidebar, the landing 'under the hood' section).

# CampusLink design system v3: 'The Register'
Concept: an institutional placement register that learned to explain itself: ruled paper, stamped decisions, margin notes. Calm, specific, printed-feeling. Not a SaaS template. Never change src/lib/store.jsx, src/api or the data flow when restyling.

STACK unchanged (Vite, React, Tailwind 3.4, react-router, framer-motion, recharts, lucide-react). Fonts through Fontsource (npm), imported in main.jsx so they work offline: Newsreader (variable, with italic), Instrument Sans (variable), IBM Plex Mono (400 and 500). If a package name fails, search npm for '@fontsource newsreader' and similar.

COLOR TOKENS unchanged (bone, paper, ink, ink-soft, line, ochre, ochre-tint, ochre-deep, jade, jade-tint, brick, brick-tint). Ochre is the only accent; text on ochre is ink. Use ochre as small SOLID areas (thread, highlighter, match bars, hover fill), never as text on bone.

TYPE: display = Newsreader, ui = Instrument Sans, mono = IBM Plex Mono.
- display-xl: clamp(56px, 7vw, 104px), weight 400, line-height .98, tracking -0.025em.
- Page title: Newsreader 44px / 1.05, weight 400. Section title: 28px, weight 500.
- Stat numeral: Newsreader 64px, weight 400, tabular-nums.
- Body: Instrument Sans 15px / 1.6. Table text: 14px.
- Label: IBM Plex Mono 11px, uppercase, tracking .12em, ink-soft. Section labels are numbered ('01 - Readiness').
- Data (IDs, roll numbers, CTC, dates, scores): IBM Plex Mono 13px.
- Emphasis inside a headline = Newsreader italic. Never bold, never a different color.

SURFACES, three levels only. L0 page = bone + a 4% paper grain (fixed overlay, SVG feTurbulence noise, pointer-events none). L1 = ruled sections: no background, no card, separated by 1px line rules; this is the default for all content. L2 = 'objects' (drawer, popover, command palette, score dial, record slip, offer letter): paper background, 1px line border, radius 10px, shadow 0 12px 32px -12px rgba(20,22,28,.18) only when floating.
RADII: controls 6px, objects 10px, stamps 3px. Nothing above 12px. rounded-full only for avatars and the sidebar marker.

COMPONENTS
- Stamp({tone, children}): mono 11px caps, tracking .14em, 1.5px solid border in the tone color, radius 3px, transparent background, rotate(-2deg), padding 3px 8px. Used for decisions: VERIFIED, REJECTED, SHORTLISTED, CLASH, RESOLVED, ACCEPTED, OFFERED. Enter: scale 1.6 to 1, rotate -8deg to -2deg, opacity 0 to 1, spring (stiffness 520, damping 24); then the parent nudges down 2px and back (thud).
- Tag({children, dot}): plain mono 12px text with an optional 6px colored dot, no box. For minor statuses (In Review, Pending, Technical Review) and skill lists.
- MarginNote({label, children}): a mono label ('AI NOTE'), then italic Newsreader 17px text, max width 62ch, no background, no border. Key phrases wrapped in <Mark> get a highlighter swipe: an ochre rectangle at 55% opacity behind the lower 55% of the text, scaleX 0 to 1 from the left over 500ms, staggered.
- Rule({strong, draw}): 1px line color (strong = 1px ink). With draw it scales from 0 to 1 horizontally on view (600ms, origin left).
- StatStrip({items}): a row between two rules, items separated by vertical hairlines; each item = mono label, Newsreader 64px numeral (count-up), one-line hint. No cards.
- Masthead({context, title, lede, action}): mono caps context line, page title, one-sentence lede in Newsreader italic 20px, optional action on the right.
- Button: height 40px, radius 6px, Instrument Sans 600 14px. Primary = ink background, bone text; on hover an ochre layer rises from the bottom and the text stays ink. Secondary = 1px ink border; hover fills ink at 6%. Text links end with an arrow that moves 4px right on hover. No shadows.
- DataTable: no zebra, no card. Header = mono label row between a strong rule above and a line rule below. Rows separated by line rules, 56px tall. Numeric columns right-aligned in mono. Hover = a 2px ochre tick on the left edge and bone darkened 3%.
- Tabs: text tabs; the active one has a 2px ink underline that slides (layoutId); counts in mono.
- Charts: hairline axes, only 3 horizontal gridlines in line color, mono 11px ticks, direct value labels, ONE highlighted element in ochre and the rest ink at 85%, no legend box, a one-line annotation under every chart.
- Icons: lucide, 1.5px stroke, only in nav, buttons and form fields. Never in a tinted square or circle, never as decoration, never the Sparkles icon.

LAYOUT: 12-column grid, content max width 1240px, 64px between sections, 32px between rows. Prefer asymmetry (7/5 or 8/4 columns) over equal columns. Every page starts with a Masthead.

MOTION (framer-motion, ease [0.22,1,0.36,1], only transform, opacity and SVG strokes). Five motions only: (1) rules draw in, (2) stamps thud in, (3) highlighter swipes, (4) numbers roll or count up, (5) table rows slide in from the left (x -12 to 0, stagger 40ms). Page enter = rule draws, then title, then content rows. No generic fade-up on every block. No hover-lift on content. Respect reduced motion.

COPY: concrete and short. Never use: seamless, powerful, empower, unlock, revolutionize, cutting-edge, next-gen, leverage, 'Welcome back', exclamation marks. Realistic Odia and Indian names, uneven CGPAs (7.84, 8.31, 9.02), no round-number data.

BANNED: any gradient (the one hatch pattern in the Drives timeline excepted), glassmorphism, shadow-lg, rounded-2xl, icon tiles, pill badges above headings, centered hero, trust-badge rows, three equal cards with three bullets, left-border callouts, emoji, Sparkles icons, pulsing glows.
